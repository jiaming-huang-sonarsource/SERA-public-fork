统计规则

轮数 = assistant 消息数，包含重试；一次工具调用不重复累计此前的输入。

清洗按 SERA 默认 Hermes + keep_only_think：保留非空 think 和工具调用，去掉 think 外叙述；无 think 或 think 为空时，将叙述包入 think。system 换成含工具说明的训练提示，工具返回包装为 user/tool_response；原始轨迹显示不变。

清洗后 token = 整条训练序列，包含 system、user、工具返回和 ChatML 标记。仅 assistant 参与 loss，其余被 mask 但仍占上下文。thought/action 等辅助字段不重复计数。超过 32k（32,768）时，仓库训练配置会丢弃整条，不截断；格式校验失败或 Qwen 未提交显示不适用。参考数据缺少 exit_status，这里仅复现格式清洗。

__TOKENIZER__。计数使用训练 ChatML 模板，不使用生成模型的原生推理模板；这是训练长度，不是多轮 API 用量之和。

工具均长的“调用 / 返回”分别是每条工具调用（名称、参数、Hermes 标记，不含 think）与每条工具返回（含包装）的平均 token 数。Patch 行数为最终提交 diff 的新增 + 删除，包含空行，不含上下文和 diff 头。
